# Глазки 👁

Маленькое приложение для Mac, которое живёт в строке меню и напоминает дать глазам отдохнуть
по правилу «20‑20‑20»: каждые 20 минут — 20 секунд смотреть не в экран.

- глазик в строке меню, без бегущего таймера сверху;
- по клику — окошко: сколько осталось, пауза, настройки;
- время работы (10 мин – 1,5 ч) и отдыха (20 сек – 10 мин) выбирается из списка;
- два вида перерыва: **«Затемнять»** — экран мягко затуманивается, по центру фраза и обратный отсчёт;
  **«В уголке»** — маленькое окошко в углу, удобно на созвонах;
- тихий звук в начале и ещё тише — в конце перерыва (колокольчик / капелька / ветерок / без звука);
- можно пропустить перерыв или отложить на 5 минут, поставить паузу на 30 минут, час или до завтра;
- если отошла от компьютера на 5+ минут или Mac уснул — отсчёт начинается заново;
- светлая и тёмная тема, автозапуск вместе с Mac.

## Как установить

1. Открой вкладку **Actions** в репозитории → последний зелёный запуск **Build** →
   внизу в разделе **Artifacts** скачай **Glazki** (это zip, внутри `Glazki.dmg`).
   Если есть раздел **Releases** — можно скачать `Glazki.dmg` оттуда.
2. Открой `Glazki.dmg` и перетащи **Glazki** в папку **Applications**.
3. Первый запуск: приложение не подписано сертификатом Apple, поэтому macOS спросит, доверяешь ли ты ему.
   Открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз и нажми
   **«Всё равно открыть»** рядом с Glazki. Это нужно сделать только один раз.
   Если macOS пишет, что приложение «повреждено», выполни в Терминале:
   `xattr -cr /Applications/Glazki.app` — и открой ещё раз.
4. Сверху в строке меню появится глазик 👁

## Для разработки

Сборка на Mac (нужен Xcode или Command Line Tools):

```bash
./scripts/build-app.sh      # → build/Glazki.app и build/Glazki.dmg
```

Звуки и иконка генерируются скриптом `scripts/make_assets.py` (нужны `numpy` и `pillow`).
Каждый push собирается в GitHub Actions на macOS; тег вида `v1.0.0` дополнительно публикует релиз.
